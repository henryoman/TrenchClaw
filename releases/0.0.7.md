# TrenchClaw v0.0.7

This maintenance release corrects stale Raydium interfaces and verifies the complete nine-file catalog against current official sources.

- Generate Raydium CLMM and CPMM interfaces from the current official program repositories with locked Anchor dependencies, replacing the older published IDL mirror.
- Include CLMM permissioned-pool and rent-collection instructions, current admin account constraints, CPMM creator-fee sharing, permissionless collection, and updated account layouts.
- Check current upstream revisions during CI and release validation. A valid local checksum alone no longer passes the freshness check.
- Provide the complete catalog in `trenchclaw-v0.0.7-idls.tar.gz`, with a SHA-256 checksum and source manifest.

Pump.fun, PumpSwap, Pump fees, SPL Token, Token-2022, Jupiter, and Metaplex interfaces were checked individually against their current official schemas. The runtime uses Jupiter REST swaps; these interfaces are reference files rather than direct trading clients.
