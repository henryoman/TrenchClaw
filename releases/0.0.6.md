# TrenchClaw v0.0.6

This maintenance release replaces retired AI model defaults and choices.

- Set `openrouter/free` as the default in the runtime, GUI, and shipped instance settings.
- Offer the Free Models Router, Nemotron 3 Ultra Free, and Gemma 4 31B Free.
- Resolve saved retired model selections to the free router when settings are loaded.
- Verify model availability, tool calling, and zero token pricing before publishing releases.

The free router selects from available free models that support the request. Its underlying model can vary between requests. An OpenRouter API key is still required by TrenchClaw.
