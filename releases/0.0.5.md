# TrenchClaw v0.0.5

This maintenance release updates Solana dependencies and Jupiter swap compatibility.

- Update Solana Kit and transaction packages to 8.4.0.
- Move managed swaps to Jupiter Swap V2 `/order` and `/execute`, preserving existing `ultra` provider settings and tool names.
- Preserve the quoted transaction message and other signer slots so JupiterZ can finish signing during execution.
- Accept both 32-byte private keys and 64-byte Solana keypairs in the shared signer.
- Refresh Jupiter setup docs and bundled swap guidance.
- Create instance directories in contract order for consistent initialization reports.
- Refresh Pump.fun, SPL Token, Token-2022, Jupiter V2 routes, Metaplex Token Metadata, and Raydium CLMM interfaces from official sources.
- Add PumpSwap, Pump fees, and Raydium CPMM interfaces, with pinned source revisions, checksums, and CI validation for the full catalog.

Raydium AMM V4 remains an archived official IDL snapshot because Raydium removed it from the current upstream catalog. The reference IDLs do not add direct protocol trading tools or generated runtime clients.

TrenchClaw adds no referral fee by default. Optional referral parameters remain available for configured Jupiter referral accounts.
