# TrenchClaw v0.0.8

This maintenance release fixes market API compatibility and refreshes bundled Jupiter guidance.

- Read Dexscreener's documented `pairs` response while retaining compatibility with its `pair` field.
- Reject unsupported `ExactOut` requests before calling Jupiter Swap V2 managed orders.
- Use current Jupiter hosts for Tokens V2, Price V3, documentation, and MCP examples.
- Use canonical crypto news sentiment and fear/greed endpoints, correct news pagination, and reject unsupported search pagination.
- Call Helius parsed swap history directly over REST, removing the SDK and its conflicting Solana dependencies while preserving continuation and error handling.
- Refresh the nine-file IDL catalog against current official upstream revisions, including the newer Pump curve schema and mayhem routing error.

Jupiter Trigger remains on the supported noncustodial V1 contract. V2 requires a separate custodial vault and authentication integration. Helius parsed swap history remains on its documented Enhanced Transactions service, which Helius labels legacy.

Verification: lint, typecheck, full tests, packaged app build, bundle validation, and upstream IDL freshness checks passed. Public reads passed for Jupiter quotes/tokens/prices, Dexscreener pairs, GeckoTerminal pools/OHLCV, and news/search/trending. Crypto news sentiment returned an upstream 503 during the audit. Authenticated Helius reads and trading mutations were covered by contract tests, not live transactions.
